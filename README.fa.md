# Xiaomi Notes TXT Importer

ابزاری برای **انتقال خودکار فایل‌های `.txt` به برنامه Notes گوشی‌های شیائومی** با استفاده از ADB.

این ابزار فایل‌های متنی را از داخل یک فایل `.zip` می‌خواند و آن‌ها را **یکی‌یکی به Xiaomi Notes ارسال و به‌عنوان یادداشت ذخیره می‌کند**.

> ⚠️ این ابزار برای Windows و گوشی‌های Xiaomi طراحی شده و برای ارتباط با گوشی به ADB نیاز دارد.

---

## پیش‌نیازها

قبل از استفاده، موارد زیر باید روی سیستم و گوشی آماده باشند.

### 1. نصب Python 3 روی ویندوز

ابتدا Python 3 را روی ویندوز نصب کنید.

برای بررسی نصب بودن Python:

```bash
python --version
```

---

### 2. نصب ADB

برای ارتباط با گوشی از **Android Debug Bridge (ADB)** استفاده می‌شود.

دانلود ADB از صفحه رسمی Android:

https://developer.android.com/tools/releases/platform-tools

پس از دانلود، فایل‌های ADB را در کنار اسکریپت قرار دهید.

برای مثال ساختار پوشه باید به شکل زیر باشد:

```text
project/
├── adb.exe
├── AdbWinApi.dll
├── AdbWinUsbApi.dll
├── import_xiaomi_notes.py
└── texts.zip
```

> در صورتی که نسخه ADB شما فایل‌های دیگری نیز دارد، آن‌ها را نیز می‌توانید در همین پوشه قرار دهید.

---

## 3. فعال‌سازی USB Debugging در گوشی شیائومی

برای اینکه کامپیوتر بتواند از طریق ADB با گوشی ارتباط برقرار کند، باید **USB Debugging** را فعال کنید.

### مرحله اول: فعال کردن Developer Options

در گوشی شیائومی:

1. وارد **Settings** شوید.
2. وارد **About phone** شوید.
3. گزینه **MIUI version** یا در بعضی مدل‌ها **OS version / HyperOS version** را پیدا کنید.
4. حدود **۷ بار پشت سر هم** روی آن بزنید.
5. بعد از فعال شدن Developer Options، پیامی مشابه زیر نمایش داده می‌شود:

```text
You are now a developer
```

### مرحله دوم: فعال کردن USB Debugging

سپس:

1. به **Settings** بروید.
2. وارد **Additional settings** شوید.
3. وارد **Developer options** شوید.
4. گزینه **USB debugging** را فعال کنید.
5. در صورت نمایش هشدار، آن را تأیید کنید.

> مسیر تنظیمات ممکن است بسته به مدل گوشی، نسخه MIUI یا HyperOS کمی متفاوت باشد.

---

## اتصال گوشی به کامپیوتر

گوشی را با کابل USB به کامپیوتر متصل کنید.

سپس در همان پوشه‌ای که `adb.exe` قرار دارد، Command Prompt یا PowerShell را باز کنید و اجرا کنید:

```bash
adb devices
```

در اولین اتصال، معمولاً پیامی روی گوشی نمایش داده می‌شود که از شما می‌خواهد **USB debugging / RSA key** را تأیید کنید.

گزینه **Allow** را بزنید.

دوباره دستور زیر را اجرا کنید:

```bash
adb devices
```

اگر اتصال درست باشد، باید دستگاه شما در لیست نمایش داده شود:

```text
List of devices attached
XXXXXXXX    device
```

# آماده‌سازی فایل‌های TXT

تمام فایل‌های یادداشت باید داخل یک فایل ZIP قرار بگیرند.

برای مثال:

```text
texts.zip
├── note1.txt
├── note2.txt
├── note3.txt
├── shopping-list.txt
└── ideas.txt
```

فایل ZIP را می‌توانید با هر برنامه‌ای مانند Windows Explorer، 7-Zip یا WinRAR ایجاد کنید.

> ⚠️ فایل‌های `.txt` باید حتماً داخل ZIP باشند. اسکریپت مستقیماً پوشه‌ای از فایل‌های TXT را دریافت نمی‌کند.

# ساختار پوشه پروژه

برای اجرای ساده‌تر، پیشنهاد می‌شود تمام فایل‌های موردنیاز در یک پوشه قرار داشته باشند:

```text
project/
├── adb.exe
├── AdbWinApi.dll
├── AdbWinUsbApi.dll
├── import_xiaomi_notes.py
└── texts.zip
```

یعنی:

* `adb.exe`
* فایل‌های مربوط به ADB
* `import_xiaomi_notes.py`
* فایل ZIP حاوی یادداشت‌ها

همگی در **یک پوشه** باشند.

# نحوه استفاده

ابتدا:

1. گوشی را با USB به کامپیوتر متصل کنید.
2. USB Debugging فعال باشد.
3. پیام تأیید Debug روی گوشی را تأیید کرده باشید.
4. فایل‌های `.txt` را داخل یک فایل ZIP قرار دهید.
5. `adb.exe`، اسکریپت و فایل ZIP در یک پوشه باشند.

سپس Command Prompt یا PowerShell را در همان پوشه باز کنید.

دستور زیر را اجرا کنید:

```bash
python import_xiaomi_notes.py texts.zip
```

بعد از اجرای برنامه، **Xiaomi Notes باید روی گوشی باز شود** و فایل‌های موجود در ZIP **یکی‌یکی به‌عنوان یادداشت ساخته شوند**.

# Command Options

| گزینه             |      مقدار پیش‌فرض | توضیح                                                                            |
| ----------------- | -----------------: | -------------------------------------------------------------------------------- |
| `zip`             |         **اجباری** | مسیر فایل `.zip` که فایل‌های `.txt` یادداشت‌ها داخل آن قرار دارند                |
| `--limit N`       | `0` (بدون محدودیت) | فقط `N` فایل اول را وارد می‌کند. برای تست بهتر است از `1` استفاده کنید           |
| `--pause SECONDS` |              `2.0` | فاصله زمانی بین ارسال هر یادداشت، تا گوشی و برنامه Notes فرصت پردازش داشته باشند |

### مثال

برای انتقال تمام یادداشت‌ها:

```bash
python import_xiaomi_notes.py texts.zip
```

برای تست فقط یک فایل:

```bash
python import_xiaomi_notes.py texts.zip --limit 1
```

برای تغییر فاصله بین انتقال یادداشت‌ها، مثلاً 5 ثانیه:

```bash
python import_xiaomi_notes.py texts.zip --pause 5
```

می‌توان گزینه‌ها را با هم نیز استفاده کرد:

```bash
python import_xiaomi_notes.py texts.zip --limit 10 --pause 3
```

# عیب‌یابی

### `No ADB device found`

اگر با خطای زیر مواجه شدید:

```text
No ADB device found
```

ابتدا این دستور را اجرا کنید:

```bash
adb devices
```

سپس بررسی کنید:

* USB Debugging روشن باشد.
* گوشی با کابل USB به کامپیوتر متصل باشد.
* پیام RSA / USB debugging روی گوشی تأیید شده باشد.
* در صورت نیاز کابل USB را جدا و دوباره متصل کنید.

---

### `More than one Android device is connected`

اگر چند دستگاه Android یا شبیه‌ساز به کامپیوتر متصل باشد، ممکن است اسکریپت نتواند دستگاه موردنظر را تشخیص دهد.

دستگاه‌های اضافه را قطع کنید.

یا اگر می‌خواهید یک دستگاه مشخص را هدف قرار دهید، می‌توانید از متغیر محیطی `ANDROID_SERIAL` استفاده کنید.

ابتدا شناسه دستگاه را با این دستور پیدا کنید:

```bash
adb devices
```

سپس:

```bash
set ANDROID_SERIAL=DEVICE_SERIAL
```

و دوباره اسکریپت را اجرا کنید.

---

### `Could not launch Xiaomi Notes share receiver`

این خطا معمولاً به این معنی است که Intent مربوط به Xiaomi Notes با موفقیت اجرا نشده است.

برای مشاهده خطای واقعی، دستور زیر را به‌صورت دستی اجرا کنید:

```bash
adb shell am start -a android.intent.action.SEND -t text/plain --es android.intent.extra.TEXT test -p com.miui.notes
```

اگر این دستور نیز خطا داد، احتمالاً مشکل از نسخه برنامه Notes، پکیج Notes یا سازگاری دستگاه است.

---

### یادداشت‌ها ناقص یا بریده‌شده هستند

اگر بعضی از یادداشت‌های طولانی ناقص یا بریده‌شده وارد Notes می‌شوند، ممکن است به محدودیت طول دستور `adb shell am start ... --es android.intent.extra.TEXT` برخورد کرده باشید.

این موضوع بیشتر برای فایل‌های TXT بسیار طولانی اتفاق می‌افتد.

برای تست، ابتدا یک فایل کوتاه را امتحان کنید:

```bash
python import_xiaomi_notes.py texts.zip --limit 1
```

# نکته‌ای درباره نحوه کار اسکریپت

این اسکریپت از `adb.exe` که در کنار خودش قرار دارد برای ارتباط با گوشی استفاده می‌کند.

فرآیند کلی به این شکل است:

```text
texts.zip
    │
    ├── note1.txt
    ├── note2.txt
    ├── note3.txt
    └── ...
          │
          ▼
import_xiaomi_notes.py
          │
          ▼
       adb.exe
          │
          ▼
adb shell am start
          │
          ▼
    Xiaomi Notes
          │
          ▼
      New Note
```

برای ارسال هر یادداشت، اسکریپت از `adb shell am start` و Intent مربوط به ارسال متن (`ACTION_SEND`) استفاده می‌کند.

متن قبل از ارسال با تابع `shlex.quote()` در Python **quote / escape** می‌شود.

دلیل این کار این است که `adb shell` آرگومان‌ها را به شکلی پردازش می‌کند که ممکن است متن‌هایی شامل فاصله یا کاراکترهای خاص به‌درستی منتقل نشوند.

بدون quote کردن مناسب، ممکن است یادداشت‌هایی مانند:

```text
My Shopping List.txt
```

یا متن‌هایی که شامل فاصله و کاراکترهای خاص هستند، هنگام ارسال به گوشی اشتباه تفسیر یا به چند بخش تقسیم شوند.

## ⚠️ نکات مهم

* قبل از شروع انتقال، مطمئن شوید گوشی به کامپیوتر متصل است.
* USB Debugging باید فعال باشد.
* در اولین اتصال، پیام RSA روی گوشی را تأیید کنید.
* فایل‌های ورودی باید `.txt` باشند.
* فایل‌های `.txt` باید داخل یک فایل `.zip` قرار داشته باشند.
* برای تست اولیه، پیشنهاد می‌شود از `--limit 1` استفاده کنید.
* برای فایل‌های TXT بسیار طولانی ممکن است محدودیت ADB باعث ناقص شدن متن شود.
* فاصله پیش‌فرض بین انتقال یادداشت‌ها **۲ ثانیه** است؛ در صورت نیاز می‌توانید با `--pause` آن را افزایش دهید.
